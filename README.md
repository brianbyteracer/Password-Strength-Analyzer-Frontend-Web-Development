A simple and interactive Password Strength Analyzer built using HTML, CSS, and JavaScript. This project checks the strength of a password in real time and helps users create secure passwords by analyzing different security factors.

Features:-
Real-time password strength checking
Detects Weak, Medium, and Strong passwords
Checks:
Password length
Uppercase & lowercase letters
Numbers
Special characters
User-friendly interface
Instant feedback for better password security

Technologies Used:-
HTML
CSS
JavaScript

 How It Works:-
The user enters a password in the input field.
The application analyzes the password based on security conditions and displays whether the password is:
Weak
Medium
Strong

Purpose of the Project:-
This project was created to understand

Password security concepts
Frontend web development
JavaScript validation logic
Cybersecurity basics

How to Run:-
Download or clone the repository
Open the project folder
Run the index.html file in your browser

Preview:-
Interactive password checker with live strength indication.
